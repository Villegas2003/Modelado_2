Proyecto de simulacion

Movimientos de Calistenia en Tiempo Real

Este repositorio es una simulacion interactiva en Python con Tkinter. Vercel necesita un archivo HTML, asi que esta pagina sirve como vitrina del proyecto y explica como ejecutarlo localmente.

La interfaz permite ajustar articulaciones y visualizar fuerzas y torques sobre el cuerpo humano con graficos dinamicos.

Que vas a encontrar

Interfaz grafica

Sliders y campos de entrada para angulos de codos, hombros, rodillas y caderas.

Motor fisico

Calculo de fuerzas y torques basado en masas y distancias configurables.

Visualizacion

Matplotlib renderiza la postura del cuerpo y actualiza en tiempo real.

Control total

Explora distintos rangos de movimiento y mira como cambian los resultados.

Como ejecutarlo en tu equipo

1

Instala dependencias con pip.

pip install numpy matplotlib
2

Ejecuta la aplicacion desde la carpeta del proyecto.

python -m src.main
Nota: el proyecto es de escritorio. Vercel solo hospeda esta pagina informativa porque la interfaz Tkinter no corre en el navegador.
